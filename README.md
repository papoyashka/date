# Программа для работы с датами

Практическая работа № 2: модульное и мутационное тестирование

## Описание

Модуль `date_utils.py` - работа с календарными датами:

- вычисление разницы между двумя датами
- определение дня недели по дате
- проверка года на високосность
- вычисление количества дней до следующего Нового года
- преобразование строки в объект даты

## Структура

- `date_utils.py` — основной программный модуль
- `README.md` — описание программы
- `test_date_utils.py` — модульные тесты (создаются на этапе тестирования)

## Запуск

Для проверки программы необходимо установить Python и запустить модульные тесты с помощью pytest:

```bash
python -m pip install pytest
python -m pytest -v
```

## Функции

| **Функция** | **Назначение** |
|---|---|
| `parse_date(date_string)` | преобразование строки в дату |
| `days_between(date1, date2)` | вычисление разницы между датами в днях |
| `weekday_name(date_string)` | определение дня недели |
| `is_leap_year(year)` | проверка високосного года |
| `days_until_new_year(date_string)` | количество дней до следующего Нового года |
